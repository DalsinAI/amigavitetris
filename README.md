vitetris for GFOS
=================

vitetris, Victor Geraldsson's text-mode Tetris (one or two players on one keyboard), for GFOS (AmigaOS 3.2 with GFOpenUp) on a 68040, in a Shell or console window.

The port is being written on branch team3/vitetris-port-20261116.

Designed, tested and delivered by The AmiCradle Team.
